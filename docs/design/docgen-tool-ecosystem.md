# 文档生成工具生态调研一览

> 本文档回答：**"市面上有和 docsforge 相同或类似的产品吗？"** 它作为
> docsforge「外部生态定位」（README 引用）的依据，从各维度盘点相邻工具，
> 并说明 docsforge 的组合差异化。
>
> ⚠️ **来源与时效声明**：以下基于长期、广泛使用的成熟工具的稳定既有知识整理
> （定位可靠）。**具体版本号、近一年新增对标工具（尤其 AI 驱动的）需联网复核**，
> 本仓库不在本文内置外部超链接，避免假引用。

## 一、按"从代码生成文档"细分找同类

| 工具 | 语言/生态 | 形态 | 是否跨语言 | 漂移/门禁 | 产出的"标准目录" |
|---|---|---|---|---|---|
| **apidoc** | JS | 代码内注释 → REST API 文档 | 部分（多语言注释） | 弱 | 仅 API 一种 |
| **Doxygen** | C/C++ 等 | 注释 → 参考手册 + 图 | 多语言 | 弱 | 参考手册 |
| **Sphinx / autodoc** | Python | docstring → 全站文档 | 单语言为主 | 弱 | 全站骨架 |
| **mkdocstrings** | Python | MkDocs + docstring 抓取 | 单语言 | 弱 | 站点化 |
| **JSDoc / godoc / rustdoc** | 各语言 | 官方注释文档器 | 单语言 | 弱 | 参考 |
| **terraform-docs** | Terraform | 变量/注释 → README 表 | 单生态 | ~强（生成区） | 单一表格 |
| **docsforge** | 任意（插件化） | `docs:` 注解 → 多类型产出 | **跨语言** | **强（一等公民）** | **按类型标准骨架** |

## 二、与 docsforge 理念最接近的对手

**terraform-docs** 与 docsforge 共享同一套哲学，只是锁定 Terraform 单生态：

- **就近声明**：在 Terraform 变量/输出附近的注释里声明描述；
- **生成区标记**：`<!-- BEGIN_TF_DOCS --> … <!-- END_TF_DOCS -->` 包裹，
  scan 只替换标记内的内容；
- **手写区隔离**：标记外的 README 手写内容绝不被覆盖。

docsforge 把这一套**泛化到任意项目类型**（参考 `docsforge.yaml` 的 structure/
roadmap L1），并从"单一表格"扩展到"API 路由表 + 配置参考 + 模块索引 + CLI 参考"多形态，
再加上**一等公民的漂移检查**（`docsforge check` 进 CI/pre-commit）。

## 三、docsforge 的组合差异化

单一特性各家都有，但**组合**是 docsforge 独有的：

1. **跨语言**：单一工具覆盖多语言/框架，而非每个语言一个独立工具。
2. **语言无关核心**：`docs:` 纯注释注解；解析/渲染/漂移/CLI 全部语言无关，
   只有 handlers/ 负责语言相关提取（插件点）。
3. **漂移检查是一等公民**：`check` 命令 + CI 门禁，不是生成器的附带品。
4. **按项目类型的标准目录**：`reference/`（生成区）+ `guides/`（手写区）物理隔离，
   结构性产出而非零散生成附件。
5. **生成区幂等 + 手写不覆盖**：只动 `BEGIN/END GENERATED` 内的内容（见 drift.py）。

## 四、互补而非替代：AI 驱动的文档生成

近年出现基于 LLM 的"从代码自动写文档"工具。它们通常走 **LLM 自动推断**路线，
与 docsforge 的 **人类就近声明 + 机器生成 + 漂移强制**哲学互补，而非替代：

- docsforge 强在"**可校验、可进 CI、永不漂移**"——适合要求文档与代码严格一致的项目；
- AI 工具强在"冷启动时快速起草"——适合当首稿，再由人类注解 + `scan` 固化。
- 具体这些 AI 工具的名录、成熟度**需联网复核**（本仓库不列名，避免过期信息误导）。

## 五、结论

docsforge **不是重复造轮子**：在"注释驱动 + 跨语言 + 生成区/手写区隔离 +
漂移门禁"的交叉点，没有现成的同等组合。最接近的是 terraform-docs（理念同源但
单生态），而 apidoc / Doxygen / Sphinx / mkdocstrings 各擅长单形态或单语言。
